# HistoryAurora 现行约定

云服务化宿主按包清单的 `role=frontend` 识别 Aurora 前端；本地候选和热装包均保留该声明。

本仓唯一的长期文档。这里只写**从代码和测试里看不出来的取舍**；做法本身以代码为准，
每版做了什么看 `git log`。条目被推翻就直接改掉，不留历史。

## Web 前端（V2.0）

- REQ-WEB-001：`b-Code-Web` 是不依赖 WPF 的 ASP.NET Core 8 前端入口；当前只监听本机 5280，
  服务端每次读取 Portunus endpoint 文件并转发调用，凭据不传浏览器。这里暂用现有 Shell 通道，
  后续公网身份、远程确认和事件传输归 Portunus；当前不能将此开发入口直接映射公网。
- REQ-WEB-002：普通编辑弹层及页面浮层使用 HTML dialog，Esc、关闭和焦点恢复在浏览器内完成；
  手机端显示全屏并支持浏览器返回。电脑端“弹出页面”使用独立浏览器窗口（用户点击触发），
  浏览器拦截时明确提示允许弹窗；普通 popup 编辑器仍在当前页面内。
- REQ-WEB-003/004：复用 V1 页面和动作声明、表格全量快照、面板、静态/动态候选、参数占位与选择通道。
  缺失参数拒绝执行，未知组件显式占位。单模块解析失败不阻断其他模块。
- REQ-WEB-005：场景包含多页。电脑同时展示场景中可见页；手机只显示一页，胶囊切换并保留已挂载内容，
  左右滑动切换相邻页，表格横滚及表单手势不切页。弹页返回保留原页面与选择。
  页面是场景内的内容单元，不把页面改成独立场景。模块自建原生桌面页面不自动转换。
- REQ-WEB-006：电脑主壳恢复“停靠画布＋右侧控制栏”，没有顶栏、常驻页标题和桌面页签行。
  初始布局按 placement 的左右上下中央构建，同位只显示第一页，其余进入右栏常用页面；
  场景是用户布局，模块归属仅用于初始种子，其他模块页面同样可拖入当前场景。
  右下页面调整开关或单独按住 Ctrl 进入标签态：标签拖到另一页的四边分割、中央替换，
  拖回右栏常用页面可隐藏；提供位置选择和隐藏按钮作非拖动入口。隐藏页点胶囊可恢复，
  记得原相邻页时恢复到原边；分隔线支持拖动与方向键调整比例。
  每个场景的树、显隐、比例和当前页自动保存在浏览器 localStorage；重开网页及重新连接优先恢复用户布局。
  恢复默认排列只重置当前场景。右栏支持搜索场景与隐藏页，标签态支持场景拖动排序和收起/放回。
  调整与手机切页移动已挂载 DOM，不重建页面组件，草稿与选择保持；Ctrl+C 等组合键不维持临时标签态。
  手机仍每次只展示一页，控制栏收在右侧，可展开；布局保存在当前浏览器，不写回桌面 Aurora 的布局设置。
- REQ-WEB-007：Web 字体与密度对齐桌面当前令牌，统一定义在 aurora.css：Microsoft YaHei UI / Segoe UI，
  正文 13px、辅助与表头 11px、Consolas 等宽 12px；普通控件最小高 28px、表格行高 30px、行内按钮高 20px。
  页面圆角 20px、内边距 12px，组件圆角 8px，组件间距 12px、面板行距 8px；右侧控制栏宽 200px。
  画布／页面／控制面板分别映射 Canvas／Surface／SurfaceAlt，两套主题各取桌面原色。
  数值来源为 AuroraTokens.xaml、AuroraTokens.Dark.xaml、AuroraControls.xaml 和 AuroraPanelBoard；
  WPF 逻辑单位与 CSS px 均以 96dpi 为基准。浏览器字体渲染遵循系统可用字体，不用页面缩放模拟桌面密度。
- REQ-WEB-008：Web 表格按桌面语义分配列宽：数字是比例权重、星列权重 200、缺省 120；
  软下限 48px，窄视口让位，始终铺满视口。首个星列固定在数据列末尾，行内操作列固定最右。
  拖动列边界调宽，末数据列吸收差额，最右边界锁定；拖动表头调整顺序，Alt+左右键也可移动。
  表头右键提供左右移动与恢复默认，分隔线方向键每次调宽 8px，双击分隔线恢复默认。
  有 id 的表格按 owner/page/id 在当前浏览器保存列序和比例权重，刷新或重开恢复，新增/移除列自动协调。
  行右键或 Shift+F10 先选中该行，所有行操作进入菜单；inline=false 仅在菜单显示。
  菜单固定行与显式参数快照，执行期间同一行同一动作防重复；列 cellStyle=double 只画文字并双击执行。
  支持声明的行内编辑：双击开始、Enter 保存、Escape/失焦取消，提交固定原行，失败还原。
  同数据源刷新失败保留原数据并显示错误，切换源参数清空旧选择，迟到响应不能覆盖新数据。
  验收：table.test.mjs 与 table-browser.test.mjs，覆盖列宽边界、拖动/重载、菜单目标、编辑、断线和窄视口。
- REQ-WEB-009：浏览器滚动条沿用桌面令牌：透明轨道宽 12px、滑块内缩 3px、可见圆角 3px，
  TextDisabled 色默认透明度 .55、悬停 .85，不显示系统箭头；不支持 WebKit 滚动条伪元素的浏览器使用细条回退。
  表格链接只在链接内部省略，取消外层单元格对链接的第二次省略，避免末端出现额外小点。
- REQ-WEB-010：Web 控制面板复用桌面 rows / minWidth / flex / even，标签独占排版格；
  放不下时同一声明行折行（间距 3px），仅声明行间画横线，同视觉行相邻格之间画竖线。
  自由输入在 Enter/失焦提交，多行输入只换行且失焦不提交；选择框左键/空格/方向键轮换，右键列出完整候选；
  choices 是折行选项条，支持 text 显示名、选中墨块、右键动作与点击项参数快照。
  动态候选保留当前项，否则声明初值/首项；缺父通道或取数失败保留旧候选，拒绝迟到响应；程序回写只发布通道，不执行业务动作。
  开关用墨块布尔按钮，action/commitAction 均可；enabledWhen.selected 真正禁用按钮，动作断链显示原因，运行态防重复。
  控件参数按面板作用域隔离，本地声明的 aurora.ui.panelset 只回写浏览器面板。
  clearOnSuccess 要求原输入与完整目标指令均未变化，旧回执不清除新草稿或其他目标的正文。
  sourcePicker 支持手输路径及双击网页内文件/目录选择；选择运行服务的电脑上的路径，不打开宿主原生对话框。
  /api/files 只列目录与校验所选路径，不读文件内容、不上传文件；沿用本机限制、同源和 X-Aurora-Web 请求校验。
  来源框支持 source/source-picker 别名，可省略 commitAction，取消选择不回写、不提交。
  验收：panel.test.mjs、panel-browser.test.mjs，覆盖提交手势、候选乱序、菜单、作用域、草稿保留、源选择与接口边界。
- REQ-WEB-011：表格不额外展示刷新/恢复列布局工具条；取数仍在首次挂载、来源参数变化或动作完成时触发，
  恢复默认保留在表头右键菜单和分隔线双击入口。表头与选中/悬停行整条绘制圆角矩形，圆角共用控制面板的 radius-inner（8px），
  首尾单元格分别收左右角，中间列不各自倒角；单列表格四角完整，滚动后表头仍保持四角。
  列序和比例权重无过期时间，按当前浏览器、站点 origin、owner/page/table-id 长期保存；清除站点数据、隐私模式结束或切换 origin 不共用。
  验收：table-browser.test.mjs 的工具条移除、选中行与表头四角、刷新失败保留数据及列布局重载恢复。
- 第一版尚未覆盖：泳道、聊天、通道驱动 switch、原生窗口置顶、文件上传下载、

  手机本地文件上传另行接入。需确认的后台命令尚不能保证确认在浏览器出现，因此不将其计入 Web 弹窗验收。

## 组件层：用描述代替文档

组件层是公共区，任何项目都可以来加组件。加的人只改两处：组件本体，和 `ComponentCatalog` 里的一条规格
（用途、字段、示例、规矩）。不写规格提交不了——`ComponentCatalogContractTests` 守着：

- 渲染器能画的节点类型、面板认的小组件种类，与目录逐个对账；
- 模型类上每个可写字段都必须有说明，说明里写的字段必须真实存在（死字段因此会被清出来）；
- 每份示例都被真的解析、渲染一遍，不许缺件、不许报 Warn。

进组件层还要守：外观封在组件里，调用方只给数据与形状，不留「默认值可覆盖」的口子；颜色字号只取令牌、
一律 `DynamicResource`；能离开主窗体的组件构造时调 `AuroraComponentResources.Ensure(this)`；
有动作就绑动作 id；带一条合同测试，并在注释里写清它为什么存在。仍然缺的组件用 `aurora.ui.request` 登记。

## 界面取舍

- **深浅两套分开设定（1.42.0）**：不拿一套主题的颜色去当另一套的颜色——1.40.0 / 1.41.0 试过反色对齐，
  无论怎么调，总有一种颜色在某一套主题里显得突兀。改色时两套各自调、各自看。
- **文字只有一种颜色（1.40.0）**：浅色 `#38352F`、深色 `#DAD7CE`（由原次要文字色 `#6A6458` / `#ACA593` 同色相往上调到第 4 档，对背景约 11:1，用户从七档样张里选定）；
  TextPrimary = TextSecondary；反色块上的字 = 本主题背景（`#FBFAF7` / `#121414`），即 OnInk = Canvas；主题色块、危险色块上的字也用 OnInk（不再有 TextOnAccent）。
  页面底色、控制面板色、墨色块用原值（1.42.0 从 1.41.0 的反色对齐退回）：
  浅色 Surface `#F3F1EC`、SurfaceAlt `#EBE9E4`、悬停/发丝线 `#E5E3DE`、墨色块 `#26231E`、表头分隔线 `#ACA593`；
  深色 Surface `#1D201F`、SurfaceAlt `#242625`、悬停/发丝线 `#2A2D2C`、墨色块 `#E2DAC6`、表头分隔线 `#6A6458`。
  墨块上的金色（AccentOnInk）已删，选中行悬停不变色。
  共用色值只在 `Aurora.Color.*` 写一次。Janus / Mercury / Minerva 直接引用 `Aurora.Brush.*`，删键前先改它们。
  验收：`InkBlockContractTests.InkTokensAreAliasesAndReadable`。

- **切换容器自带页签（REQ-UI-161，1.39.0）**：`switch` 不写 `source` 时自带一行页签，每支的 `case` 就是页签名；
  不取数、不重建的规矩与通道版同一套（页签行借 TabControl，内容不放进 TabItem——Loaded 沿逻辑树广播）。
  组件测试页据此收成四个页签，不再平铺。验收：`PageSwitchContractTests.ASwitchWithoutSourceDrawsItsOwnTabsAndKeepsTheSameRules`。

- **表格列竖线（REQ-UI-162，1.39.0）**：表格行不画底部横线，改为列交界处的竖发丝线（ControlBorder），
  与表头墨块上的列分隔线对齐、首列左侧不画；选中墨块盖住本行竖线。外观只在 `Aurora.Table.Row` 一处。

- **双击执行的格（REQ-UI-160，1.38.1）**：`columns.cellStyle` 新增 `double`——格画成普通文字，单击只选中这一行，
  双击才执行 `cellAction`。给「点名称就打开」又要能选行的列用；起因是 Janus 总览的项目名。
  验收：`CellActionContractTests.DoubleClickCell_FiresOnlyOnSecondClick`。

- **选项条（REQ-UI-158）**：面板小组件 `choices`，候选一字排开、点选即选中并发上通道，右键某一项弹出声明的
  `menu`（动作参数 `{value}` 取被右键的那一项）。取数、留住选中项的规矩与 select 选项框同一套；每项复用开关样式
  （选中是墨色块），不另起模板。面板上任何动作成功后重取全部候选——候选不是表格，页面刷新够不着它们。
  起因是 Janus 的分支控制；验收：`PanelChoicesContractTests`。

- **表格行内编辑（REQ-UI-157）**：`columns.cellEditAction` 与 `editableWhen` 提供通用编辑格；
  Enter 提交、Escape 还原，失焦与程序刷新不保存。动作参数使用编辑开始时的行快照，同名列替换为新值，
  切换选择不会改写目标；失败还原，运行中禁止重复提交。验收：`CellEditContractTests`。


- **本地已读动作（REQ-UI-150）**：`chatTimeline.readAction` 只在消息成功显示、组件可见且滚到最新时调用，
  参数 `{readThrough}` 是已显示行集的最大 `ts_ms`；动作取当前选择的快照，在异步调用前固定参数。
  组件不存平台已读状态；水位持久化与未读排序归业务模块。隐藏、失败、空载荷或阅读历史不确认已读。
  验收：`ChatComponentsContractTests.ReadActionRequiresVisibleLatestMessagesAndUsesSelectedIdentity`。

- **新消息会话上浮（REQ-UI-149）**：会话顺序由数据源按最后消息时间提供；首行身份变化时，
  通讯录回到顶部露出新首行，保留当前聊天选择。首行没变的普通刷新保留列表滚动位置。
  验收：`ChatComponentsContractTests.PromotedConversationBecomesVisibleWithoutChangingSelection`。

- **消息区层次（REQ-UI-148）**：聊天时间线直接铺在页面背景上，不再套一层圆角底板；
  入站气泡用次级表面色，出站气泡用强调色。验收沿用 `ChatComponentsContractTests` 的浅深色渲染与滚动检查。

- **通讯录密度（REQ-UI-147 / REQ-UI-156）**：会话卡片保留 38px 头像与标题、摘要两行信息；
  来源与单聊／群聊放在时间下方，未读徽标同行。验收：`ChatLayoutFitsViewportAndSupportsBothThemes` 的位置断言与浅深色、窄宽窗渲染预览。

- **成功后清空输入（REQ-UI-154）**：动作可声明 `clearOnSuccess` 控件 id 列表；面板只在命令成功、
  输入和动作参数未变且面板未重建时清空，不触发提交。失败或等待期间的新草稿保留。
  `sourcePicker.commitAction` 可省略，此时只选择文件，由显式按钮提交。
  验收：`ComposerClearsOnlySuccessfulUnchangedSubmission`。

- **图片气泡（REQ-UI-155）**：图片保持比例并贴满气泡，气泡尺寸跟随图片；空正文不留文字区域，
  非空图片说明保留。图片按实际尺寸裁圆角，横图、竖图与窄窗口都不变形。
  验收：`ImageBubbleFollowsImageAspectRatio`。

- **通讯组件（REQ-UI-143～146）**：`conversationList` / `chatTimeline` 共用既有选择通道与刷新台账；
  模块只给行集和语义，不自建聊天控件。会话列表刷新保留同 id 的选中；切目标或失联清空旧内容，
  不沿用表格「失败保留原内容」的策略，避免显示旧对话造成目标误认。输入框 `multiline=true` 时
  Enter 只换行，失焦不提交；发送另用显式动作按钮。字段与数据形状看组件自描述，验收看
  `ChatComponentsContractTests`（含浅深色与窄窗布局）。

- **模块只描述语义，长相归 Aurora。** 描述里不接受样式键与颜色，只有语义档位；模块不得自建组件。
- **缺能力就补通用组件或通用指令，不给某个模块、某一页开特例。** 补的东西形状沿用已有的（`optionsSource` 与
  `dataSource` 同形，浮窗走 `aurora.ui.float` 而不是模块专用组件）。
- **不许静默失败。** 未知组件渲染成显式占位并进缺件账；动作、通道断链在界面上直说并可查；
  描述解析失败整份作废（半张页面比没有页面更难排查），但只跳过这一个模块。
- **取数与程序回写不是用户动作。** 取数走安静通道，不回显、不入历史；程序回写控件不触发提交。
- **一格一页。** 每个位置任何时刻只放一页，没有页签行，没有顶栏，没有专注态。
- **场景只是一份布局，布局归用户。** 模块只能声明自己场景的页；用户保存的布局优先于声明；热重载只换内容，不重排、不抢位。
- **人手调过的样子默认跨重启。** 停靠布局、主窗体位置、表格列序与列宽、页面浮窗都记在 Aurora 数据目录的设置里。
  列宽记**比例权重**不记像素（像素随窗口变，记下来就错）；页面浮窗退出或模块卸载时收回停靠区只是为了关得掉进程，
  账上仍记「浮着」，下次登记进来原位浮出——只有人亲手还原才算不浮。页面浮窗右上角有关闭叉（REQ-UI-159，1.38.1）：点叉＝人亲手还原，
  页面回停靠区原位；原本隐藏的页（模块拿按钮浮出的「弹窗页」）还原后照旧隐藏，看上去就是关掉了。验收：`DockingContractTests.FloatWindowCloseButtonRestoresThePage`。
- **弹窗是嵌在主窗体里的卡片，不开独立窗口。** 浮出类窗口（页面浮窗、弹窗）都不加投影。
- **块用圆角，线用直线。** 颜色字面量只在两份令牌文件里，其余代码一律引用（门禁扫源码）。
- **页面不滚，组件滚。** 表格与泳道拿剩余尺寸、自带视口；页面不长横向滚动条。
- **控制台只显示宿主唯一日志。** 任何模块经宿主执行的指令过程都进控制台，Aurora 不另记一份。

## 工程约定

- `Shell/` 下五个层目录 `0-Neutral` ～ `4-Composition`，依赖只能向下，命名空间跟目录走；
  加层同时改 `HistoryAurora.Module.csproj` 的 `Include` 与 `LayerContractTests` 的层名表。
- 根目录只允许 `a-` / `b-` / `z-` 前缀的文件夹。`z-Publish/` 根部是当前候选、`history/` 是不可变归档，
  都纳入 git，任何忽略规则不得触碰。
- 发版改三处版本号：`AuroraVersion.props`、`Module/module.manifest.json`、`project.manifest.json`。
  漏改 module.manifest 热装会报「未形成可用加载快照」，原因只在宿主日志里。
- `vulcan.app.*` 与 `vulcan.module.*` 是宿主↔前端的中继协议名，按字面量转发，不随「域跟实现方走」改名。
- pack URI 用程序集名（`/HistoryAurora;component/…`）；资源名由 csproj `Link` 决定，`Link` 必须吃掉层目录。
- 晚于 Attach 登记的界面指令宿主看不见：内置指令一律在 `BuiltinCommands.Register` 里无条件登记。
- 施工方案、需求书、计划表不留存：做完即删，仍有效的结论写进本文或测试注释。
- **图片消息（REQ-UI-151）**：chatTimeline 可选 imageSource，只读指令返回 base64；消息行的 images 只承载安全的附件相对路径。按可见区域并发加载缩略图，点击在页面内放大，Escape 或关闭返回；每条最多 16 张，8 MiB、4000 万像素上限，切会话取消旧请求，缺原件明确提示。验收：ChatComponentsContractTests 图片加载、预览、取消与解码边界。
